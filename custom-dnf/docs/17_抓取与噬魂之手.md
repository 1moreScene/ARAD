# 抓取与噬魂之手（40JP，2026-10-12）

用户调整本轮目标为`GrabBlastBlood`（噬魂之手）。当前`skill/swordmanskill.lst`中的skill31为Bloodlust；全目录没有WaveSlash，不能将噬魂之手、NormalWave或HitBack称作裂波斩。

## 可核对的官方链路

- `0x5EF0A0`鬼剑士攻击回调在state22、尚未绑定、skill31时，检查目标ActiveObject、vt+824（0x338）以及`0x4AED20`当前伤害类型≤1，发送state22绑定载荷，并禁用双方相关受击/攻击使能。
- `0x4AED20`读取运行时覆盖`+644`或当前动画帧DAMAGE TYPE `+112`。类型1（SUPERARMOR）通过这一门，类型2（UNBREAKABLE）不通过。
- vt+824具体为`0x4D5C10`：检查对象`+6740`可用、`+6552`独立状态通道为0，且未冻结/石化。它与当前动画的SUPERARMOR类型不是同一个字段；不要把所有霸体直接等同于`+6552`。本轮按用户规则将保护类型与可抓取属性独立建模，不扩展声称已复刻所有异常状态。
- `0x5F39F0`state22初始分支使用Grab动作第3帧；成功分支使用第16帧，并创建CNGrabbedBlastBlood附加物与角色GrabBlastBlood动画。
- `0x650D50`检查施术者state22与目标state9，绑定目标位置并覆盖目标反应；`0x650E80`使用朝向±43、Y偏移-1、高度`max(10,110-height)`。
- `0x5F10C0`state22分支：100ms调用吸血伤害、播放BLOOD_SUCK；750ms创建PO20017喷发、播放BLOOD_SPREAD、调用`0x5F0460`释放，并取level info列2/3创建力量附加物。
- `0x5F0460`恢复目标受击使能、清理目标指针并移除抓取附加物。目标销毁通知另见`0x5EE6F0`。

本地PVF的`.mob/.ani/.atk/.chr`扫描没有`[grabable]`字面标签。因此本轮`GrabState.grabable`是与原运行时可抓取旗标对应的明确接口；怪物解析器兼容较新/本地脚本的`[grabable] 0/1`，缺省true，不声称该标签已在40JP原包中得到证实。

## 数据与实际行为

一级skill31读取原PVF：consume MP25经已有官方0.9倍率截断为22，冷却4000ms；level info为`164 328 5000 20`。static data倒地保持1200ms。身体、时装和武器使用Grab.ani；技能血气使用角色Effect/Animation/GrabBlastBlood.ani；喷发按PO定义的basic motion加载GrabBlastBlood2.ani，并使用每帧ATTACK BOX。

抓取探测只在身体Grab动画有ATTACK BOX时执行，三个轴必须重叠。选择第一个可抓取的活目标；不可抓取目标不会阻挡其他合法目标。一个目标只能有一个绑定所有者。成功后固定目标位置，停止普通受击/移动推进，施术者获得独立来源的无敌；100ms吸血一次，750ms喷发一次，强制释放被抓取目标，周围敌人由喷发盒各命中一次。旁观者的霸体只抑制普通受击反应，无敌旁观者不受伤。

失败不伤害、不赋予无敌和力量，但已成功施放仍消耗MP并进入冷却。目标死亡、复活、移除、变为无敌/不可抓取，或施术者离开动作时解除绑定，清除本技能的无敌来源，不删除调试或其他Buff来源。控制台暂停期间不推进抓取计时。

力量加成显示在角色属性里，独立于基础力量，在5秒后到期；本轮沿用训练场简化伤害模型，将普通攻击按力量比缩放。完整装备/力量/防御公式、异常状态、服务器状态请求与网络回执仍未完整复刻。训练角色显式解锁一级skill31；强制取消是训练场设置，不代表原版新角色已学会CancelGrabBlastBlood。

## 中文说明与调试

`data/skill/swordman/{hardattack,upperslash,grabblastblood}.skl`为UTF-8中文描述覆盖。只替换name/name2/explain/level property/command key explain；等级、MP、冷却、图标、伤害列和物品消耗从当前原PVF读取，避免中文覆盖过期后改变战斗数值。说明格式化支持多行模板并按当前等级替换数值。后续实装技能应同步加入中文覆盖和表值不变回归。

默认D施放噬魂之手；K技能窗可以拖拽到A/S/D/F/G/H。F6人物/怪物页新增可抓取/不可抓取，怪物可作用于单只或全部，和普通/霸体/无敌独立组合。人物开关是共用状态接口，目前怪物AI尚没有抓取人物技能。

`--grab-selftest --out out/grab-verified`输出18项状态/频率组合CSV，以及抓取、吸血、喷发、调试开关和中文说明截图。回归另覆盖100/750ms门、5秒Buff、范围伤害仅一次、死亡/复活/移除/传送中断，以及60/120/300Hz完整轨迹和声音一致。
