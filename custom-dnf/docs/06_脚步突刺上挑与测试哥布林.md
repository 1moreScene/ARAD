# 脚步、跑动攻击、上挑与测试哥布林

本轮全部进入可玩窗口：方向键移动／奔跑有循环脚步声，奔跑中X执行突刺，Z执行上挑；场景默认摆放一个原版哥布林测试靶。

后续修订：哥布林动作/装备、卡肉、硬直、推移与倒地弹跳已重新取证并替换旧测试模型，见[07](07_哥布林动作与受击反馈取证.md)；UI和原版伤害精灵见[08](08_角色信息UI与伤害数字.md)。下方115项与旧峰值为首次接入时的历史结果。

| 操作 | 当前行为 |
|---|---|
| 方向键／左右双击 | 走／跑，同时启动WALK_SOIL_LOOP／RUN_SOIL_LOOP |
| 普通X | 三段普攻，符合帧门的新按键可续段 |
| 奔跑中X | DashAttack突刺，水平减速、纵深和朝向锁定 |
| 空中X | 每跳一次，下降时可以命中地面哥布林 |
| Z | 初始1级上挑，消耗7 MP，冷却2秒；空中／其他攻击中不启动 |
| F5 | 重置哥布林位置、HP与命中计数，MP补至150；保留技能冷却 |

哥布林不主动攻击，HP设为300。命中后可观察血条、伤害数字、原版斩击特效、语音、受击姿势、击退和浮空；死亡3秒后自动复活。它是测试设施，未接正式怪物AI或掉落。

## 取证与实现

行走声音入口在`src/game/ui/char_server_info.cpp`的58FC30（按地区选土／石）；跑步声音在`src/game/equ_buff.cpp`的4B89D0 case11，按角色重量等条件选石／土／草。当前洛兰及68000重量基础鬼剑士使用土质标签。其他地图材料分支尚未完整实现。

`audio.xml`中WALK_SOIL_LOOP对应pub_wrk_01.wav，RUN_SOIL_LOOP对应pub_run_01.wav，后者LOOP_DELAY为0.15秒。声音线程保留一个移动循环声部，持续播放到文件结束后等待配置间隔，再从头开始；状态变化时替换或撤销声部，起跳／攻击时撤销。停声仍受设备已排入的缓冲延迟影响；失焦单独清空设备队列。

独立跑动攻击为状态12：4B89D0切this[1813]的DashAttack，读取上一时刻控制器水平速度的整数绝对值；this[1982]=4由5EEE40设置。491C70对前4帧各自做`int(delay×100/播放速率)`后求和，按这个时刻求整数减速度并停止于零。重制保留该独立状态、锁定方向／y及动画结束门，使用官方DashAttack.ani和DashAttack.atk、SM_THRUST语音。原版技能11对突刺的装备／技能覆写尚未实现。

上挑技能编号是**46**，swordman.chr初始等级1。`skill/swordman/upperslash.skl`记录MP7、冷却2000ms及第一行增伤10／浮空300／推力100。`bigfunc_5F10C0_sub_5F10C0.cpp`请求state24并传`[2,46]`，`bigfunc_5F39F0_sub_5F39F0.cpp`将24映射8，段号2选择第三击动画，同时换成UpperSlash.atk并发SM_UPPER_SLASH。**不能使用HardAttack.ani代替上挑。** 当前Z对应这个基础上挑入口，不具备已学习取消上挑后的普攻取消或完整霸体／技能装备修正。

普通／空攻／突刺／上挑均读取武器层的真实ATTACK BOX；哥布林从真实动画读取DAMAGE BOX。盒子为`[x,y,z,width,depth,height]`，以世界脚点和高度定位，左右朝向镜像x，三轴均需重叠。两个武器层合并，单个测试目标在每次攻击动作只结算一次；空挥、纵深错开和高度不相交不扣HP。动作结束后不保留攻击判定。

哥布林素材路径为`monster/goblin/goblin.mob`、`Animation_Goblin/Stay/Damage1/Down.ani`、`Monster/Goblin/body1.img`；命中特效为`common/hiteffect/animation/slashsmall1.ani`。普通受击与真正倒地按.atk的damage reaction区分，避免微小lift up让所有普通攻击错误倒地。死亡和受击分别触发R_GOBLIN_DIE、R_GOBLIN_DMG，武器命中使用R_MINERALSWDA_HIT／MINERAL_SWDB_HIT。

**伤害仍为测试模型，恢复已按后续原版取证修正。** 默认基础测试物攻5+13，可在信息面板调整，乘.atk百分比并取整，上挑使用.skl第1级增伤10。默认HP300，双方各100ms独立停顿、普通375ms恢复及约30px减速推移；倒地经历脚本帧门、首次落地弹跳、第二落地500ms与Sit150ms，当前上挑回放峰值72px。完整STR／防御／元素／暴击伤害公式和特殊反馈分支仍待接入。

声音预载现为17标签／28个文件，支持所用原版8位／16位PCM。两个Sound Forge文件省略奇数data的pad：minSwdA_hit_02在EOF、gbn_die_02在LIST元数据前；解析器针对这两个结构位置兼容，并继续检查块边界和完整PCM帧。

## 验证

115项工作区测试覆盖独立突刺、帧4减速结束、上挑MP／冷却／长按／空中拒绝、三轴碰撞、单动作命中去重、正常三段与下降空攻命中、上挑浮空、死亡／重置、循环间隔／撤销及WAVE兼容。clippy `-D warnings`、fmt通过。

```powershell
cd custom-dnf
cargo test --workspace
cargo run --release -- --headless --script dashattack --frames 120 --trace
cargo run --release -- --headless --script upper --frames 180 --audio-out out/upper.wav
cd ..
python tools/verify_custom_battle.py
python tools/verify_custom_audio.py
```

`out/battle-verified/verification.json`记录走／跑声音、突刺1次命中、上挑2次命中及75.4px峰值；同目录有实际800×600窗口截图和可听音轨。最后一次四种窗口回放队列耗尽均为0，音轨均无16位触顶采样；此结果不替代原版客户端声音／延迟／完整战斗公式的逐项对照。
