## 当前窗口和调试

M或I打开/关闭，F6展开/收起调试。属性窗保留原版(29,63)和日文底图；装备窗置于右侧，以当前时装/武器的Stay动作合成人物。鼠标悬停铁剑图标可查看物品信息。

鼠标或Tab选值，输入数字后Enter或“应用”提交；加减一次点击修改一次；非法范围保留原值并提示。“恢复默认”回到本次加载的脚本初始数值，不写回PVF，也不持久化到下次启动。HP/MP上限降低会夹取当前值。动作属性使用原版内部单位，例如移速/攻速850代表85%。新属性从随后逻辑/动作使用，已经创建的跳跃轨迹不会中途重建。

| 调试组 | 作用 |
|---|---|
| 基本/战斗 | HP/MP与上限、测试物攻、哥布林HP上限、数字样式 |
| 动作参数 | 移速、攻速、跳跃力/跳跃速度、重量实际写入ActorSpec；等级用于面板显示 |
| 角色属性 | 力量/智力/体力/精神及防御/魔攻面板调试；完整派生公式尚未接入 |

HP/MP、动作、基础属性与抗性初值从swordman.chr读取；默认测试物攻为基础5+铁剑.equ13。抗性含光-20/暗20。当前伤害仍使用测试物攻×ATK倍率，不会因调力量/防御就自动调用尚未实现的官方完整公式；鬼剑士HP暂没有敌方攻击消耗。装备区为当前默认武器展示，尚无物品拖拽、更换装备和完整背包。

面板打开时暂停战斗时钟/脚步，所有编辑按键先由UI消费；Esc先关闭面板，再次按Esc退出。中文动态文字使用Unicode GDI缓存字形，原版NeopleFontFile尚未加载，因此动态字体不声称逐像素一致；底图、插画、图标和伤害精灵均为官方素材。

## 伤害数字

| 当前调试样式 | Combo数字起始帧 |
|---|---|
| 0普通（黄色） | 143 |
| 1暴击显示（红色） | 88 |
| 2绿色（原版type2） | 64 |
| 3蓝色（原版type3） | 74 |
| 4受伤 | 54 |
| 5附加伤害（灰白） | 44 |

样式选择用于验证渲染，不会额外制造暴击、附加伤害、治疗或魔法伤害结算。正常攻击默认黄色。旧版误把143标为暴击专用：448CF6..448D5F证明该最后参数实际是攻击来源与本地对象的比较，不能直接当成暴击位。红色数字88..97为原图集现有素材，按用户确认的红色暴击规则用于显示；完整官方暴击触发链选择88尚待继续核对。每个数字动画共500ms，五帧如下；前帧开插值时过渡到下一帧，否则保持。

| 帧 | 延迟 | 比例/位置/alpha |
|---|---|---|
| 0 | 100ms | 普通2→1倍，受伤1.4倍；y=-h/2；普通保留黄色，暴击标志/受伤首帧白闪；插值 |
| 1 | 200ms | 普通1倍、受伤1.4倍；原位置、不插值 |
| 2 | 100ms | 从原位置至上移15；alpha255→128；插值 |
| 3 | 100ms | 上移15→30；alpha128→0；插值 |
| 4 | 0ms | 上移30、透明，动画结束 |

字间距为每张图宽-5，总宽`sum(width)-5*(n-1)`，起点`total_width/-2`。每组位置固定在本次命中盒中心z+50，按世界y-z投影、减相机x；不追随怪物被推移的位置。连续攻击保留独立多组数字，对象卡肉不停止数字时钟。

Combo.img的数字为tag0x0F A4R4G4B4，保留4位alpha与颜色；已修正以前误按A1R5G5B5解析的实现，防止边缘与颜色失真。后续精灵变换与显示改为双线性，IMG0x0E色位补齐已与原版静态UI逐像素核对；详见09，整帧D3D浮点细节仍未全部对拍。
