# 300Hz 世界与不限速渲染

官方40JP `0x4052D0` 时间系统读取`timeGetTime`差值，并保留倍率运算后的余数；动画DELAY、技能冷却与动作计时使用毫秒。本地证据没有证明原版固定60Hz，此前文档中的“原版60Hz”应更正为旧重制逻辑/回放设置。

运行窗口使用`WORLD_MS=1000/300`的独立时钟，绘制与提交没有FPS上限。`Game.step`将60/120/300Hz驱动提供的经过时间统一切为300Hz世界量子，余数保留；每量子推进输入、人物、怪物、碰撞、技能和计时。追帧预算限制一次处理的量，但保留积压时间，不丢弃时间使世界变慢。移动速度仍以每秒计，动画仍使用ANI毫秒与播放倍率，冷却/Buff/抓取仍使用毫秒。相机原32px/60tick限制改为1920px/s；伤害反馈改为750ms，避免次数计时变快。

这保证新300Hz世界在不同调度频率下结果一致，并提高命中窗口的采样密度；不声称与旧60Hz离散采样的每一个边界瞬态完全相同。旧核心直接Actor测试保留60Hz默认参数，窗口和Game世界执行300Hz。

`--frames`、`--shot-after`和脚本事件保留60Hz参考时间含义：240帧仍是4秒，不是0.8秒；窗口日志另报实际逻辑步数。FPS表示实际窗口绘制/提交次数，与显示器物理刷新率、世界更新Hz不同。

验证：

- `cargo test --workspace`验证移动、跳跃、攻速、技能、命中停顿、碰撞、动画边界与追帧积压。
- `--timing-selftest --out out/timing-verified`比较60/120/300Hz驱动下每50ms的完整快照、浮点位值、冷却、伤害与声音序列。
- 抓取回归额外比较7秒内的绑定目标位置、动作帧、无敌窗口、冷却与力量Buff；验证100ms吸血、750ms释放、5秒Buff。
- Release性能验收包含普通1/6/32怪物、32霸体、控制台、6怪物抓取保持及32怪物喷发。全部通过，最终数据见`out/performance-grab-row/verification.json`。
