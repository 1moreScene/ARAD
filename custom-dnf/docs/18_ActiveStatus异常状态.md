# ActiveStatus异常状态（40JP，2026-10-12）

本轮读取本地ARAD.exe、Script.pvf及NPK。状态名称来自PE的`off_791F38`十八项表：0..16为状态，17为none。状态对象`CNRDActiveStatus`以17个独立槽挂在活动对象上，每槽有自己的等级、来源、计时与参数；同类型再次施加刷新该槽，不覆盖其他类型。

## 官方数据与调用链

- `0x4D6030`：无敌门、冻结/石化动画许可、睡眠对被抓取状态的许可，随后懒创建状态槽并转发。
- `0x497300`：状态等级上限40；施加、刷新、解除及属性重算通知。
- `0x497120`：从`0x6CB268`的17组一级/40级参数插值。`0x497150`读取`0x6CB2F0`第二参数表。
- `0x4971B0`：持续时间取`0x6CB220`固定秒数，或由状态等级参数换算为毫秒并截断。
- `0x5FAD60`：减速/加速修正移速与攻速，诅咒/祝福修正四维；冰冻火抗-50、水抗+50；石化体力+100；控制状态写相应抗性通道。
- `0x5FB830`/`0x5FD010`/`0x5FD310`：进入、更新和退出。眩晕/睡眠互斥；冻结与石化阻止抓取；束缚只限制主动位移。
- `0x5FA9A0`：有效受击触发感电追加攻击；睡眠经过200ms保护期后受击解除，连续扣血不是普通受击。
- `0x5FCA50`/`0x5FC450`：中毒与灼烧连续按经过时间结算HP，小数/累计量不丢失；飘字观察者每500ms汇总。`0x5FC610`出血每1000ms结算，非等待动作伤害增为1.5倍。
- `0x5FC120`：灼烧对距离小于200的其他活动目标造成范围伤害；`0x5FC2F0`：石化提前解除时按剩余比例结算碎裂伤害。
- `0x497560`/`0x4976E0`：石化以60×60为基准、冰冻以130×140为基准，按宿主图像尺寸缩放。状态效果不能照原始大图无缩放地套在小怪上。
- `0x497840`、`0x5FAFC0`：状态ANI/PTL装配、前后层与身体颜色调制。失明的屏幕遮挡属于受影响的本地观察者，不应让测试怪物失明后遮黑玩家画面。

`tools/active_status_evidence.py`重新读取原文件，保存状态标签、两组参数、固定时长、46份状态资源、20份ATK样例、关键函数汇编和PE/PVF哈希到`work/active_status_evidence/`。原资源包保持不变。

减速与加速、诅咒与祝福按独立属性修正项叠加，移除后恢复基础值；不把状态倍率写回基础属性。中毒/灼烧伤害和状态命中概率应用相应抗性，免疫阻止新增状态；已经存在的持续伤害仍单独结算。感电、睡眠唤醒和灼烧范围攻击不会递归生成新的同类攻击。死亡/复活/移除清理状态与粒子，抓取与异常状态的绑定分别维护。

### 当前工程边界

活动对象使用现有训练场属性与防御模型，四维修正接入该模型，完整装备/四维派生、PVP平衡、等级差和服务器状态同步仍未完成。火属性伤害沿用训练场的抗性比例模型。巡逻按钮是调试演示，不是完整官方怪物AI；失明视野范围与混乱行动在该演示中有实际影响，怪物尚无完整攻击技能AI。不能把本轮实现扩展为所有DNF版本、所有怪物的完整行为复刻。

## 调试操作

1. F6打开控制台，选择“怪物”，指定“全部怪物”或“单只”。
2. 进入“异常状态”，打开下拉框；勾选标记表示当前目标集合已经存在该状态。
3. 调整等级1..40，点击“添加/刷新”；其他类型保持。
4. “移除所选”或点击已有状态条目，只移除该类型。普通石化移除触发碎裂伤害；“清空状态”是调试清理，不触发碎裂伤害。
5. 多于十种状态时用状态页箭头查看后续条目。混合标记表示部分怪物拥有或参数不相同。
6. “巡逻演示”用于观察减速、加速、束缚、混乱和控制状态。关闭面板后计时继续；面板内的状态时钟暂停。

下拉框选择本身不施加状态，也不清空旧状态。两个保留项可以查看说明，但不会伪造效果。人物/怪物的霸体、无敌、可抓取开关仍在属性页，和ActiveStatus分开维护。

## 渲染与验证

状态图像、帧号、DELAY、循环、IMAGE POS/RATE、RGBA和LINEARDODGE来自ANI；粒子对象、频率、寿命、运动轴、重力、透明度、发射区域、最大时间/数量、落地消失来自PTL。连续发射及-1频率的一次性碎石发射分别处理；没有靠降低粒子数量提升FPS。

固定精灵变换在装载时保持线性采样预处理，绘制时保留动态透明度与调色；非透明连续像素段跳过透明空白。SSE4.1白色调制混合有标量回退，整数除255、饱和加法和目标alpha的结果逐字节对照。状态声音使用官方XML/WAV；同类持续音共享独立循环声部，与脚步声分别启停，声音总数仍有预算上限。

`--active-status-selftest --out out/active-status-verified`导出15个有效状态、14状态叠加、下拉框、状态清单、碎冰/碎石截图及17项状态CSV。回归覆盖独立刷新/到期、控制互斥、状态伤害/抗性、500ms反馈、感电触发、睡眠唤醒、抓取、死亡重生、范围/单只设置、面板暂停、60/120/300Hz一致性及真实资源的缓存/原始绘制逐像素一致。最新性能记录见`out/performance-active-status-release/verification.json`，普通原生FPS与CPU密集场景分别报告。
