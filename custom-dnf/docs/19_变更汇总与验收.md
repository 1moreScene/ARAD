# 状态、调试、时钟与性能变更汇总

## 实现范围

- 霸体、无敌按帧、动作及临时来源独立管理，加入轮廓反馈；上挑只在取证确认的动作阶段获得霸体。见[保护状态取证](13_霸体无敌状态与轮廓取证.md)。
- 移除窗口置顶及焦点抢回，保留右上角FPS；F6自绘控制台调整人物和怪物属性、保护、可抓取与数量，F7查看性能。见[调试控制台](14_自绘调试控制台与多怪物.md)。
- 世界逻辑默认300Hz，画面绘制不限频；经过时间驱动运动、动画、技能及命中，兼容60/120/300Hz外部推进。官方证据为毫秒时钟，未证明其固定逻辑Hz。见[时钟说明](16_300Hz世界时钟.md)。
- 实现GrabBlastBlood（噬魂之手）的抓取、吸血攻击、喷血、释放与临时力量加成，霸体可抓取，无敌或不可抓取拒绝；鬼斩、上挑、噬魂之手的技能描述使用中文SKL文本覆盖。见[抓取取证](17_抓取与噬魂之手.md)。
- 接入40JP ActiveStatus的15个有效类型及17项枚举，支持独立计时、多状态并存、状态伤害、属性修正、控制、原资源动画/粒子/音效和下拉调试。致命攻击、元素在该版本无执行分支，保留编号及说明。见[异常状态说明](18_ActiveStatus异常状态.md)。
- 优化双线性缩放、混合、透明区裁剪、静态场景与精灵缓存；持续伤害飘字按官方500ms节奏汇总，伤害仍按经过时间结算。见[性能准则](15_性能指标与渲染优化.md)。
