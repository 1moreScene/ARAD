# 自绘调试控制台与多怪物（2026-10-12）

本轮取消游戏窗口置顶/抢焦点，移除世界画面里的动作、坐标、动画帧、冷却、快捷键说明、FPS和按键调试文字，新增独立自绘控制台。原版HP/MP胶囊、技能栏、冷却显示、伤害飘字、怪物血条与施放失败通告继续作为游戏UI绘制。

后续修订：按用户要求恢复右上角FPS，其余诊断仍只在控制台显示；新增性能指标与优化，最新程序路径见[15_性能指标与渲染优化](15_性能指标与渲染优化.md)。

## 操作

- **F6** 打开/关闭控制台，不需要先打开 M/I 信息窗口。
- **F7** 打开控制台的运行信息页，查看动作、位置、FPS和最近按键记录。
- **Esc** 或右上角关闭按钮关闭控制台；关闭时不会退出游戏或触发下方HUD按钮。
- 打开控制台暂停世界；输入数字不会触发攻击、技能或跳跃。鼠标选择数值、输入数字后 Enter 或“应用数值”提交；Tab 选择下一项，左右加减按钮直接提交。
- **F8/F9** 在游戏中仍可快速切换人物测试霸体/无敌。F5重置测试怪物和人物MP，清除这些调试状态。

## 人物页

“基础属性”显示并编辑当前/最大HP、MP、物理/魔法攻击与防御、力量、智力、体力、精神。“动作参数”编辑移速、攻速、跳跃力、跳跃速度、重量、等级和飘字样式。底部可选普通/霸体/无敌、补满HP/MP或恢复人物默认值。

本轮复用既有属性模型：HP/MP限值、物理攻击和动作参数会影响实际运行；等级、四维与其他攻防仍属于调试数值，完整官方属性派生和完整伤害公式尚未接通。状态按钮设置独立调试来源，不修改PVF或取消技能自身的帧门；上挑仍只有帧索引0/1的动作霸体。

## 怪物页

数量范围 **0–32只**，实际生成/移除场景中的测试哥布林。新怪物共享官方.mob/.equ/IMG资产，每只独立维护HP、动作、卡肉、恢复、浮空、命中次数与状态。新增怪物按房间通行范围排列，继承主测试怪物的HP上限、防御、重量与硬直恢复设置。

“全部怪物”将输入值应用到所有活动怪物；“单只”配合左右选择按钮编辑某一只。全部模式中不同数值显示“混合”，不同保护状态不会错误显示为统一状态。

| 项目 | 实际作用 |
|---|---|
| HP上限/当前HP | 修改目标生命；当前HP为0进入死亡，正值可以复活 |
| 物理防御 | 训练伤害按 `damage × 1000 / (1000 + defense)` 缩减，最少1点 |
| 重量 | 进入现有上挑/击倒的实际浮空与推力公式 |
| 硬直恢复 | 进入现有受击硬直持续时间公式 |
| 普通/霸体/无敌 | 切换目标独立状态来源；无敌跳过命中，霸体扣HP但抑制普通反应 |
| 复活并重置 | 重置选定范围的HP/动作/命中次数，保留已设属性和状态 |
| 恢复默认 | 恢复1只默认属性、普通状态的测试哥布林 |

现有怪物仍是测试靶，未新增正式主动攻击AI或完整官方防御公式。防御缩减是本地训练模型，默认0保持原有伤害回归结果。

## 多目标战斗与显示

攻击分别检查每只怪物的三维受击盒，同一动作对每只目标最多命中一次。一只目标无敌不会阻止其他目标命中；新的普攻段/技能清除上一动作的目标命中记录。怪物在人物前/后按脚点y排序绘制，继续遵守地图close层遮挡。怪物状态轮廓使用已有红色/白色显示策略。

## 窗口行为

Win32呈现器只读取前台/输入焦点，已经删除置顶、SetForegroundWindow、SetFocus、AttachThreadInput和F10钉住逻辑。失焦/最小化不接收游戏输入，世界与声音继续运行；重新获得焦点采用输入基线，避免后台按住的按键/鼠标变成新点击。控制台打开时世界暂停属于编辑行为。
