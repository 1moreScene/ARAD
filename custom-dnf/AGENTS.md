# custom-dnf 质量与性能准则

- 世界逻辑默认300Hz，窗口绘制/提交不限频；官方时间证据为经过毫秒，未证明固定60Hz。60Hz仅为旧回放的参考时间单位。显示器刷新率、逻辑更新Hz与渲染FPS必须区分。调整频率必须验证物理/输入/命中时序。不可通过跳过逻辑、虚报计数、降低双线性采样或丢弃角色/装备图层改善FPS。
- 右上角保留FPS；坐标、帧号、详细耗时等调试信息放入F6/F7控制台。
- 改动渲染、显示缩放、场景合成、多怪物或状态轮廓时，除功能回归外必须运行Release性能基准，记录平均帧时间、P95/P99、慢帧、渲染/缩放/呈现分段耗时。CPU基准与原生窗口FPS分开报告，性能测试串行执行。
- 本机参考验收（i5-1235U，800×600显示）：普通1/6怪物CPU渲染+缩放平均≤3.333ms；普通32怪物≤4ms；32霸体怪物≤8.333ms；控制台≤5ms。原生普通场景平均≥300FPS，最近240帧P95≤5ms，超过16.667ms的比例≤1%。其他硬件需注明环境和单独预算。
- 入口：`--performance-benchmark --out out/performance`；仓库根目录`tools/verify_custom_performance.py --enforce`执行预算检查。性能相关修改应与保存的旧Release对比，使用`--baseline`进行相同工作负载和像素验证。
- 缓存必须正确处理相机、动画帧、朝向、透明度与资源变化；优化数学/像素路径需验证与参考路径一致。单项通过后，仅因新改动、失败或未解决问题重复测试。
- ActiveStatus压力场景：单怪物同时14状态绘制+缩放平均≤3.333ms；32怪物同时14状态≤8.333ms；带状态的下拉控制台≤5ms。持续伤害按实际时钟连续结算，飘字按原版500ms汇总，不能逐HP点无限生成；不得通过减少状态、粒子或图层通过预算。
