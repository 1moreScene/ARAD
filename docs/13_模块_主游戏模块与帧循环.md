## 3. 模块切换处理器 sub_41CC80（from → to 迁移矩阵）

- 模块类型枚举（字符串自证）：1=MAIN_GAME / 2=SELECT_DUNGEON / 4=PVP / 6=WARROOM；
  0/3/5 待定案。to ∈ {3,4,6} → 战斗标志(0x77F488)=0。
- from 侧：1（+216 标志 −1）/ 3（四连复位）/ 4（停 UDP+日志）/ 5（横幅 27）/
  6（停 UDP + 横幅 1925/1926 按子模式）。
- to 侧（要点）：进 1 = 声音全停 + **g_shakeRateX=100 复位（仅 X，Y 不动——原样）** +
  上下文槽清理（vt+1020）+ sub_425960 场景装载；进 2 = MAP_APPEAR 音效 + 座位
  （sub_456420）+ UDP START；进 4/6 = LADDER_DOWN 音效 + 玩家 vt+1056(1)；
  进 3 时若 from==2 有专属分支（41C190/vt+160）。
- 收尾 sub_44EA20(from, to)。

## 4. 退出链

main loop 退出标志 → 确认对话（vt+20(10)、vt+16(84)）→ **sub_41C1E0**：

## 5. ★ 发包 API（sub_423200/423380，曾误判为镜头特效）

两步式：`packet_send_begin(conn, type)` 构造 12 字节包头 {01, type} 并申领上下文；
`packet_send_commit()` 填总长（缓冲+12）、序号（+464 WORD 自增）、校验和（sub_48BE40）、
按**包名表 off_790928[type]** 记 "[-> COMMAND PACKET] Packet : %s, Size : %d,
CheckSum : %d" 日志，type==3 置发送锁(+466)（登录包锁发送），实际发送 sub_698A50，
失败且主管理器存在 → 本地播报串 145（网络错误提示）。
连接对象字段：+8 已连接 / +448 发送缓冲 / +452 上下文 / +460 长度 / +464 序号 / +466 锁。
