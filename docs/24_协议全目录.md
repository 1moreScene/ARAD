## 五、底层协议格式

包头（12 字节）：+0 BYTE 附加标识 / +1 WORD 包类型 / +3 DWORD 校验和(sub_48BE40) / +7 起为包体。
发送流程：Begin(type) 构造包头 → Append(body) 逐字段 → Commit() 校验和+日志+发送。
type==3(登录) 时自动置 SendLock（防止未登录就发其他包）。
