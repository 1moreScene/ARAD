## 4. 地址粗分区（函数密度 + CRT 边界）

- 0x400000-0x660000：游戏代码主体（密度 127-561 函数/64K 块）
- 0x660000-0x6A0000：**CRT 静态运行库**（__input/__output/__woutput/__pow_pentium4/
  __fltout2 等已命名；重建时以标准库引用替代，不做逐函数还原）
- 0x6A0000-0x6C1000：代码尾/填充（少量 thunk）
- 0x6C14F8-0x77F000（.rdata）：虚表农场 + RTTI 三件套 + 常量池
- 0x77F000+（.data）：全局对象（已知锚点：0x8F7C04 本地玩家、0x79D100 tick 数组、
  0x9B0C70/0x99FC80 全局时钟）

## 5. RTTI 命名工程（P2 定案）

- TypeDescriptor：**746 个**（即 746 个有 RTTI 的类）
- Complete Object Locator：**1,518 个**（多继承 → 多 COL）
- 虚表：**783 张**，方法槽位合计 **95,686**（跨子类共享基实现后去重更低）
- 有虚表的类：730；最大槽位数 341（CNAxeExpeller 等怪物类）
- **定义者命名**：沿基链 root→derived 找槽值首次出现类（ introducer ），
  已回写 **3,540 个函数**到 IDA 工作库（`work/ARAD_recon.i64`），
  命名格式 `类名__vmt槽偏移`（如 `IRDActiveObject__vmt200`）
- 命名质量抽查：与 42 轮研究定案五点全吻合（0x4D71B0/0x49A320/0x4E6770/0x4E82B0/0x4D4D40）
