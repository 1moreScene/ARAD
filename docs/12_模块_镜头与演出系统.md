## 3. 变焦族（研究 P6 的完整机制化）

- `0x424530 camera_zoom_command`：统一入口（暴击 1.5×/受击 1.2×/连击冲拳 2.0×）。
  选项门 sub_48B740(2)；斜率 = reach×|target−current|/(target−1)；
  mode: 1=向目标渐入 / 2=保持 / 3=向 1.0 渐出。
- `0x425570 camera_zoom_tick`：逐帧推进（mode 1/2/3 分支；焦点 -1 → 自动跟随玩家
  vt+120/124/128，fx'=x−320、fy'=y−120−z）。尾部写全局【推断】（反编译截断，存证 verify3）。
- `0x424F00 zoom_restore` / `0x423910 zoom_reset` / `0x4238E0 zoom_remaining`。
- 应用层：`0x424680` 点变换（p'=pivot+(p−pivot)×zoom）、`0x424760` 四边形提交
  （横向剔除 640 线 + 变焦后宽高）、`0x424980` 矩形变换（640×480 边界保留）。

## 4. ★ 语义修正（推翻研究 P5 定名）

研究 P5 称 sub_424EA0 为"定向震动"。本会话主模块 vmt4 反编译显示它在**每帧**
以用户设置档（0/0.3/0.7/1.0）调用该函数 → 它实为**用户震动强度应用器**：
写 +1356（系数）、rate[3]=strength×100、基线 rate[1]/[2]=衰减率×系数×100。
X/Y 不同系数的来源 = +1360/+1364 是衰减率（非"方向强度"）。
已同步修入源码注释与 docs/90。
