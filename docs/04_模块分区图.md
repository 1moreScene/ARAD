# 04 · 模块分区图（地址段 → 子系统）

> 更新：2026-10-06。数据源：data/module_partition.txt（每 64K 块字符串引用画像）+ 42 轮研究定案。
> 用途：源码重建的导航地图 + 任何函数定位的第一线索。

## 版本身份

- **`Ver. 200606130k0515`**（@0x48 块字符串）：客户端编译版本标记，与 PE 时间戳 2006-06-13 一致。
- 第三方库：zlib（0x65）、FMOD 3.x（声音，研究已定案）、d3d8（0x68 加载器）、
  wininet（HTTP，0x57）、flex/yflex 残留（yy_create_buffer，0x65）、MSVCRT 静态 CRT（0x67-0x69）。

## 技能/职业代码分区（重建排期依据）

2006 客户端技能区（42 轮研究 §4.3 提及"技能区 0x52-0x62"）实测细分：
- 0x5E 格斗家系（R_FT）→ 0x5F 鬼剑士系（SM_GUE/大剑/血爆）→ 0x60-0x61 通用 PassiveObject + 格斗粒子
- 0x4C 枪手武器状态机 → 0x53 枪手技能 PassiveObject
- 0x64-0x65 气功/通用光环状态

## CRT 与不可还原区（以标准库引用替代）

0x660000-0x6A0000 的 CRT/系统层（~1,100 函数）+ zlib + D3D wrapper：
源码重建中一律引用标准库名（如 `printf`/`memset`），不逐函数还原。
个别有自证名（ISocket/nIIme/NCEdit — 这些是 Neople 自研，**要还原**）。

## 待深挖块（sub 密集、named 低）
