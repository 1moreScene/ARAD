# 21 · 系统速查手册 —— 按游戏功能查函数

> 用法：想研究某个游戏功能 → 在下表找到它 → 拿到 VA 地址 → `grep -rn "0x地址" src/` 定位源码。
> 全部地址都经源码逐行核实（置信度：已证实为主，个别标【推断】）。
> 深入文档列指向 docs/ 的详细分析篇章。
