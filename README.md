## 源码还原的硬规范

1. **每个函数必须携带原地址**：函数头注释 `// VA: 0x4D71B0`，保证可回二进制逐字节对照。
2. **置信度三级标注**：【已证实】（反汇编直证）/【推断】（多证据链）/【待验证】（单一线索）。
3. **命名有据**：优先采用 RTTI 类名、字符串自证（如 "CRITICAL ERROR : CNRDSkill::flushSkillParameter"）、
   前期 42 轮打击感研究定案；纯猜测名一律 `CN suspect_xxx` 或保持 sub_XXXXXX 原名。
4. **不做字节级复刻承诺**：目标是语义忠实的可读源码（C++），不承诺重编译出同 md5 二进制
   （2006 年 VC6/VS2005 编译器行为 + 增量链接/PDB 全部缺失，字节级复刻不可行也不必要）。
5. **主库只读**：`DfoVibration_OLD_40JP\work\ida\ARAD.exe.i64` 为只读母本，本工程用
   `work\ARAD_recon.i64` 副本，毁坏即从母本重拷。
